# รายชื่อสถานที่เที่ยวเขาใหญ่

สกิลประจำ workspace: [trip-map-planner — ค้นหาที่เที่ยว ตรวจหมุด และสร้างแผนที่เลือกจุดแวะ](.agents/skills/trip-map-planner/SKILL.md) เรียกใช้ด้วย `ใช้ $trip-map-planner ...` แล้วบอกต้นทาง จุดที่ต้องไป และปลายทาง ใช้กับทริปใหม่ได้โดยเก็บแยกจากทริปนี้

รวม 45 รายการ แบ่งเป็น 10 หมวด • ปรับปรุง 13 ตุลาคม 2569

[เปิดสมุดเที่ยวเขาใหญ่ — ตัวอย่าง UI แผนที่น่ารัก](index.html)

เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง ภาพรวมเป็นแผนที่ภาพร่างสำหรับทดลอง UI มีหมุด 45 สถานที่และจุดหมายหลัก 4 จุด ค้นหา กรองหมวด/โซน กดหมุดอ่านรายละเอียด และเปิดนำทางได้ ตำแหน่งหมุดและเส้นทางในภาพร่างไม่อิงมาตราส่วนและไม่ใช้เทียบระยะจากเส้นทางจริง

เปิดหน้าเว็บแล้วแสดงภาพรวมเป็นค่าเริ่มต้น สลับไปแผนที่จริง OpenStreetMap ได้ หมุดจริงใช้ Leaflet พร้อมสีและไอคอนตามหมวด ขณะนี้มีพิกัดครบทั้ง 45 สถานที่ Take Me Home Park และศูนย์วิจัยไร่สุวรรณใช้หมุดที่ผู้ใช้ยืนยัน ส่วน Palio นำออกจากรายการตามคำสั่งผู้ใช้ และจุดเริ่มต้นขอนแก่น/วิลล่าจากพิกัดผู้ใช้ จุดที่ยังไม่มีพิกัดยังเลือกอ่านรายละเอียดและเปิด Google Maps ได้ แต่ไม่ปักตำแหน่งคาดเดา ปุ่ม “รอบเขาใหญ่” แสดงภาพรวมบริเวณเที่ยว และ “รวมจุดเริ่มต้น” ขยายไปถึงขอนแก่น หมุดอื่นยังอยู่เมื่อเลือกสถานที่

เมื่อปรับไฟล์สถานที่หรือหมวดในสารบัญ ให้รัน `node generate-html.mjs` เพื่อสร้าง HTML ใหม่

ไฟล์หน้าเว็บแยกเป็น `index.html` (โครงสร้าง), `styles.css` (หน้าตา), `app.js` (การทำงาน) และ `places-data.js` (ข้อมูลสถานที่ที่สร้างจาก Markdown) ใช้ dropdown เลือกหมวดหมู่และโซน เก็บไฟล์เหล่านี้ไว้ในโฟลเดอร์เดียวกันเพื่อเปิดจากเครื่องได้โดยตรง แก้โครงสร้างต้นฉบับที่ `page-template.html` ก่อนสร้าง HTML ใหม่

ปุ่ม “รายละเอียด” เปิดหน้าต่าง “รายละเอียดจุดนี้” แสดงคำอธิบายสถานที่ กิจกรรม ข้อดี ข้อเสีย/ข้อจำกัด ข้อควรระวัง และเหมาะกับใคร ครบ 45 แห่ง แหล่งข้อมูลแยกอยู่ในส่วนที่กดขยายได้ บันทึกตรวจสอบเดิมเก็บในไฟล์ Markdown และไม่แสดงเป็นเนื้อหาหลักของหน้าเว็บ ข้อดีและข้อจำกัดเป็นการสรุปช่วยเลือกจากข้อมูลที่มี ไม่ใช่คะแนนหรือรีวิวจากประสบการณ์ตรง

เลือกดูตามหมวดด้านล่าง แล้วเปิดลิงก์เพื่ออ่านรายละเอียดและระดับการยืนยันข้อมูลก่อนจัดเส้นทาง เลขรายการคงตามรายการเดิมเพื่ออ้างอิงกับไฟล์สถานที่ได้ง่าย แต่ละสถานที่อยู่ในหมวดหลักเพียงหมวดเดียว แม้บางแห่งมีทั้งคาเฟ่ สวนดอกไม้ หรือกิจกรรม

## แผนที่ OpenStreetMap

กด **⛶** ข้างแท็บแผนที่เพื่อเปิดเต็มจอได้ทั้งภาพรวมและแผนที่จริง กด **✕** เพื่อย่อกลับ หรือใช้ Escape บนคีย์บอร์ด เบราว์เซอร์ที่ไม่รองรับ/ไม่อนุญาต Fullscreen API จะขยายแผนที่เต็มพื้นที่หน้าเว็บแทน โดยยังมีแถบเบราว์เซอร์ หมุด ตำแหน่งฉัน และรายละเอียดสถานที่ยังใช้งานได้

พื้นแผนที่ออนไลน์จาก © OpenStreetMap contributors; ใช้ Leaflet 1.9.4 ซึ่งเก็บไว้ใน `assets/vendor/leaflet/` พร้อมใบอนุญาต ไม่มีการดาวน์โหลดพื้นแผนที่เก็บไว้ใช้ออฟไลน์ และปุ่มนำทาง/แผนที่ภายนอกยังใช้ Google Maps

เลือก “แผนที่จริง” แล้วกด “📍 ตำแหน่งฉัน” และอนุญาตตำแหน่งในเบราว์เซอร์ เพื่อแสดงหมุดสีน้ำเงินและวงความคลาดเคลื่อน พร้อมเลื่อนแผนที่มาที่ตำแหน่งปัจจุบัน กดซ้ำเพื่อขอตำแหน่งใหม่ (ไม่ได้ติดตามอัตโนมัติ) หมุดยังอยู่เมื่อเปลี่ยนตัวกรอง ต้องเปิดผ่าน HTTPS หรือ localhost และเปิดบริการตำแหน่งบนอุปกรณ์ พิกัดนี้เก็บเฉพาะในหน่วยความจำของหน้าเว็บ ไม่บันทึกลงไฟล์หรือ localStorage

## ไอคอนสำหรับแอปและ Shortcut

มี `manifest.webmanifest` ระบุชื่อแอป “เที่ยวเขาใหญ่” และเปิดแบบ standalone พร้อมไอคอน PNG ขนาด 192/512, ไอคอน maskable 512 สำหรับการครอบไอคอนบน Android, Apple touch icon 180 และ ICO หลายขนาดสำหรับ Desktop ใช้ลายรถกับภูเขาชุดเดียวกับ favicon

หลัง deploy ไฟล์ทั้งหมดบน Cloudflare Pages แบบ HTTPS ให้เปิดเว็บด้วย Chrome/Edge แล้วเลือกติดตั้งแอปจากเมนูเบราว์เซอร์ บน iPhone ใช้เมนูแชร์ → เพิ่มไปยังหน้าจอโฮม การเพิ่ม manifest และไอคอนยังไม่ได้เพิ่มโหมดออฟไลน์ให้เว็บ
