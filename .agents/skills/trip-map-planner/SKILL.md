# แผนเที่ยวเลือกจุดแวะ

ช่วยให้ผู้ใช้เลือกแวะเที่ยวได้เอง ด้วยข้อมูลที่อ่านง่าย หมุดที่ตรวจแล้ว และปุ่มนำทาง ไม่จัดตารางบังคับเที่ยวครบทุกจุด เว้นแต่ผู้ใช้ขอ

## รับโจทย์

- ใช้บทสนทนาและไฟล์เดิมก่อนถามซ้ำ แยกต้นทาง จุดนัดพบ ที่พัก และปลายทางที่ต้องไป ออกจากจุดเที่ยวที่เลือกแวะได้
- รับปลายทาง จุดหลัก วันเดินทางถ้าทราบ และความสนใจ ถ้าขาดข้อมูลจำเป็น ให้ถามเฉพาะส่วนที่ทำต่อไม่ได้ พร้อมค้นหาส่วนที่ชัดเจนไปก่อน
- ถ้าขอไอเดียหรือให้ถามก่อน เสนอรูปแบบที่ตัดสินใจได้ก่อนสร้างเว็บ เมื่ออนุมัติให้ทำแล้ว ทำต่อโดยไม่ขออนุมัติขั้นตอนเดิมซ้ำ
- ทริปใหม่ใช้โฟลเดอร์แยก เช่น `trips/<trip-slug>/` เว้นแต่ขอแทนที่ทริปเดิม ไม่ทับข้อมูลเขาใหญ่เพราะขอเที่ยวจังหวัดใหม่
- เมื่อแก้เว็บนี้หรือใช้เป็นต้นแบบ อ่าน [references/workspace-web.md](references/workspace-web.md)

## ค้นหาตามเส้นทาง

- ตรวจชื่อไทย/อังกฤษ ชื่อเก่า สาขา ที่อยู่กับรายการเดิมก่อนเพิ่ม ไม่เพิ่มซ้ำเพราะสะกดต่างกัน เก็บรหัสเดิมให้คงที่
- ตรวจข้อมูลปัจจุบันจากสถานที่ อุทยาน กรมศิลปากร หน่วยงานท่องเที่ยว หรือช่องทางทางการของร้าน ใช้รีวิวประกอบและแยกจากข้อมูลที่สถานที่ยืนยัน
- อิงถนนที่ผู้ใช้จะขับ ไม่ใช้เส้นตรงระหว่างหมุดสรุปว่า “ผ่านแน่นอน” ถ้าไม่ได้คำนวณเส้นทาง บอกว่าเป็นตัวเลือกตามแนวเส้นทาง แยกใกล้ถนนหลัก ออกนอกเส้นหลัก และเข้าเมืองตามหลักฐาน
- แยกเวลาเที่ยว เวลาอ้อม และเวลาขับทั้งหมด ระบุประมาณการให้ชัด ไม่แต่งเวลาอ้อมเมื่อไม่มีข้อมูลเส้นทาง
- ตรวจเปิด/ปิดและประกาศตามวันเดินทาง หมุดใน Maps ไม่ยืนยันว่ายังเปิด ระบุวันที่ประกาศ/วันที่ตรวจ และความไม่แน่นอน
- ถ้าขอแนะนำ เสนอรายการพร้อมเหตุผลก่อนเพิ่ม ถ้าเลือกหรือสั่งเพิ่มแล้ว เพิ่มได้เลย

## ตรวจพิกัด

- เทียบชื่อ สาขา อำเภอ ที่อยู่ และเบอร์โทรเมื่อมี เก็บหลักฐานและวันที่ตรวจในบันทึกพิกัด
- ลิงก์ค้นหารวมไม่ยืนยันหมุดร้าน ค่า `@lat,lng,zoom` เป็นกล้องแผนที่ ไม่ใช่พิกัดสถานที่
- ใช้หมุดเฉพาะ เช่น `!3dLAT!4dLON`, ข้อมูล POI ที่ผูกกับชื่อ/ที่อยู่ หรือพิกัดที่ผู้ใช้ยืนยัน ตรวจลำดับ latitude, longitude และเทียบพื้นที่ที่ควรอยู่
- แยกหมุดกลางพื้นที่ โรงงาน ตัวอนุสาวรีย์ และสำนักงานใหญ่ ออกจากประตูเข้า ลานจอด ร้านขายของ บอกขอบเขตตามที่ตรวจได้
- ถ้าไม่มั่นใจ อย่าปักคาดเดาหรือเปิดนำทางไปจุดนั้น ส่งตัวเลือกที่มีหลักฐานและลิงก์ให้ผู้ใช้เลือก ถามสาขาหรือหมุดเฉพาะ ไม่ถามกว้างซ้ำหลังได้ที่อยู่
- จุดรอยืนยันยังอ่านรายละเอียดได้ แต่ไม่แสดงหมุดจริง ปุ่มแผนที่ค้นหาชื่อได้พร้อมข้อความรอยืนยัน
- Leaflet กับแผนที่สาธารณะไม่จำเป็นต้องมี API key อย่าผูกสกิลกับ endpoint ภายใน Google ที่อาจเปลี่ยน ใช้ลิงก์ที่ส่ง การตรวจหน้าแผนที่ หรือแหล่งพิกัดที่ตรวจเทียบได้ตามเครื่องมือที่มี

## รายละเอียดสำหรับคนเที่ยว

ใช้ [references/place-template.md](references/place-template.md) เมื่อเพิ่มไฟล์สถานที่ ให้มีประเภท/จุดเด่น กิจกรรม ข้อดี ข้อเสีย/ข้อจำกัด ข้อควรระวัง เหมาะกับใคร และเวลาเผื่อเที่ยว เพิ่มสถานะที่ควรรู้เมื่อมีประกาศที่ตรวจได้

สรุปจากข้อมูล ไม่อ้างว่าไปเอง ไม่แต่งข้อเสียหรือคะแนนรีวิว ให้เห็นข้อมูลเที่ยวก่อน บันทึกตรวจพิกัดเก็บต่างหาก แหล่งอ้างอิงกดขยายดูได้

## หน้าแผนที่

ใช้ความชอบที่เลือกสำหรับ workspace นี้เป็นค่าเริ่มต้น ปรับได้เมื่อผู้ใช้ขอ:

- UI ภาษาไทย น่ารักชวนเที่ยว โทนครีม เขียว พีช Google Font Mali หรือฟอนต์ที่เลือก การเคลื่อนไหวเบา ๆ ไม่รบกวนหมุดและเคารพ prefers-reduced-motion
- เปิด **ภาพรวม** เป็นภาพวาดช่วยเลือกจุด ไม่ใช้เทียบระยะ มีแท็บ **แผนที่จริง** ใช้ Leaflet/OpenStreetMap พร้อม attribution
- แผนที่เป็นส่วนหลัก รายการกระชับ ค้นหา/กรองหมวดและโซนผ่าน dropdown หรือ dialog ไม่เปลี่ยนเป็นหน้า card โดยพลการ
- มีปุ่ม **⛶ เต็มจอ** ทั้งภาพรวมและแผนที่จริง พร้อมปุ่มย่อกลับ ใช้ Fullscreen API เมื่อรองรับ และขยายเต็ม viewport เมื่อไม่รองรับ/คำขอถูกปฏิเสธ คงหมุด ตำแหน่งฉัน และรายละเอียดสถานที่ไว้ ปรับขนาด Leaflet เมื่อเข้า/ออกเต็มจอ
- แสดงหมุดที่ยืนยันทั้งหมดเมื่อไม่กรอง เลือกหมุดแล้วยังเห็นจุดอื่น แยกจุดหลักจากจุดเที่ยว
- ใน **แผนที่จริง** มีปุ่ม **📍 ตำแหน่งฉัน** ขอสิทธิ์ตำแหน่งเมื่อกด แสดงหมุดสีน้ำเงินพร้อมวงความคลาดเคลื่อนและเลื่อนแผนที่มาที่ผู้ใช้ กดซ้ำเพื่ออัปเดต ไม่ติดตามอัตโนมัติเป็นค่าเริ่มต้น ดูรายละเอียดการทำงานใน [references/workspace-web.md](references/workspace-web.md#ตำแหน่งปัจจุบัน)
- ไม่วาดเส้นทางถนนจริงโดยไม่มีข้อมูล routing ภาพร่างระบุไม่อิงมาตราส่วน ถ้าจะใช้ routing ให้ตรวจเอกสารบริการปัจจุบันก่อน
- ปุ่ม **นำทาง** เปิด Google Maps ด้วยพิกัดยืนยัน **แผนที่** เปิดหมุด Google Maps เฉพาะสถานที่ **รายละเอียด** เปิด **รายละเอียดจุดนี้** ไม่รับรองว่าจะบังคับเปิดแอป Google Maps ได้ทุกระบบ
- มือถือแผนที่เด่น ปุ่มแตะสะดวก ตัวกรองไม่เบียด รายละเอียดไม่บังปุ่มปิด ไม่มี horizontal scroll ของหน้าและ scroll ซ้อนที่ไม่จำเป็น
- แยก HTML/CSS/JS/ข้อมูล รักษา favicon, icon, manifest และ shortcut เดิมไว้ ปรับตรงทริปใหม่เมื่อจำเป็น ไม่เพิ่ม offline/service worker โดยอัตโนมัติ

## ตรวจและส่งมอบ

- Generate จากต้นฉบับ ตรวจจำนวน รหัสซ้ำ ลิงก์ไฟล์ หมวด พิกัด แหล่งข้อมูล และรายละเอียดครบ
- ตรวจนำทางว่าปลายทางตรงหมุด ปุ่มแผนที่ชี้สถานที่เดียวกัน จุดรอยืนยันไม่ปะปนกับหมุดตรวจแล้ว
- ทดสอบค้นหา กรอง เลือก/ปิดรายละเอียด สลับแผนที่ และ mobile/desktop ด้วยเบราว์เซอร์ถ้ามี ถ้าตรวจได้เฉพาะโค้ด รายงานขอบเขตตรง ๆ
- ตรวจตำแหน่งฉันทั้งสำเร็จ กดซ้ำ ปฏิเสธสิทธิ์ หาตำแหน่งไม่ได้ หมดเวลา และเบราว์เซอร์/บริบทไม่รองรับ หมุดไม่ซ้ำและไม่หายเมื่อกรอง แยกผลทดสอบตำแหน่งจำลองจากการทดสอบบนอุปกรณ์จริง
- ตรวจเข้า/ออกเต็มจอด้วยปุ่มและ Escape รวมกรณี Fullscreen API ไม่รองรับ/ถูกปฏิเสธ สลับแท็บ เปิดรายละเอียด และตำแหน่งฉันได้ แผนที่ไม่เสียขนาดและคืนการเลื่อนหน้า/โฟกัสหลังออก
- ตรวจ arrays ของหมวดและการจัดหมุดเมื่อเพิ่มข้อมูล ไม่ให้ป้ายจุดหลักบังหมุดอื่น
- ส่งไฟล์พร้อมวิธีเปิด/อัปโหลดตามคำขอ การอนุมัติสร้างแผนไม่ได้อนุมัติเผยแพร่ภายนอกโดยอัตโนมัติ

## ตัวอย่าง

`ใช้ $trip-map-planner ไปเชียงใหม่ ออกจากขอนแก่น แวะเพื่อนที่พิษณุโลก แล้วพักแม่ริม หาจุดเที่ยวใกล้ทางและเสนอ UI ก่อนทำเว็บ`

`ใช้ $trip-map-planner เพิ่มจุดที่ฉันเลือกลงแผนเดิม ตรวจพิกัดตรงสาขา ถ้าไม่แน่ใจส่งมาให้เลือก`
