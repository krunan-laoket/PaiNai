# เว็บเดิมเป็นฐาน

อ่านเมื่อแก้เว็บนี้หรือสร้างทริปใหม่ โฟลเดอร์ workspace อยู่สามระดับเหนือโฟลเดอร์สกิล (`../../../` จาก trip-map-planner/) ไม่อาศัยชื่อโฟลเดอร์หรือ path ของเครื่องหนึ่ง

## ไฟล์

- README.md เป็นสารบัญหมวดและวิธีเปิดเว็บ; สถานที่/*.md เป็นรายละเอียดและพิกัด; บันทึกตรวจพิกัด.md เก็บหลักฐาน/ความไม่แน่นอน
- page-template.html เป็น HTML ต้นฉบับ มี __PLACE_COUNT__; generate-html.mjs อ่านสารบัญ/Markdown และสร้าง index.html กับ places-data.js ไม่แก้ข้อมูลผลลัพธ์จนไม่ตรงต้นฉบับ
- app.js/styles.css เป็นการทำงาน/หน้าตา; assets/vendor/leaflet/ เก็บ Leaflet พร้อม license; assets/icons/ และ manifest.webmanifest เป็น favicon/shortcut
- แก้ข้อมูลแล้วรัน `node generate-html.mjs` จากโฟลเดอร์ทริป ใช้ Node.js ไม่ต้อง build framework เปิด index.html หรือเสิร์ฟ static ได้

## เพิ่มรายการ

- หัวหมวด parser เป็น `## ชื่อหมวด (N รายการ)` แถวเป็น `| ID | [ชื่อ](สถานที่/ชื่อไฟล์.md) |` อัปเดตจำนวนสารบัญ
- ใช้รหัสถัดจากค่าสูงสุด ไม่ใช่จำนวนรายการ + 1 เพราะมีรายการเคยลบ ไม่เปลี่ยนรหัสเดิมหรือนำรหัสที่ลบกลับมาใช้
- หมวดยึดหัวข้อ README; arrays icons/tints/centers ใน app.js เรียงตามหมวด ตรวจให้ครบเมื่อเพิ่มหรือจัดเรียง และปรับการวางเมื่อเกินที่รองรับ
- หัวข้อ/field ดู [place-template.md](place-template.md)

## จุดหลักและหมุด

- trip ต้น app.js มี title/sub/icon/coords เมื่อยืนยัน และ x/y สำหรับภาพร่างเท่านั้น labelSide:'left' ใช้ย้ายป้ายเมื่อบังจุดอื่น
- จุดหลักที่ไม่ชัดใช้ query กับ needsBranch:true ปิดนำทาง แต่ค้นหาแผนที่ได้
- สถานที่ใช้ mapCoords จุดหลักใช้ coords; coordinates(p) อ่านทั้งคู่ แต่ query(p) เดิมเลือก coords/mapQuery/query ตามลำดับ
- ตั้งคำค้นแผนที่เป็น lat,lng สำหรับหมุดยืนยัน เพื่อให้ปุ่มนำทางตรง mapCoords ถ้าแก้ query ให้อ่าน mapCoords โดยตรง ตรวจสถานที่เดิมด้วย
- maps เป็นลิงก์หมุดเฉพาะ Google Maps ใช้ CID เป็นสตริง ไม่ผ่าน JavaScript Number ซึ่งอาจเก็บ integer ใหญ่ได้ไม่แม่นยำ
- สถานที่รอยืนยันให้ตัด field พิกัด ใช้คำค้นชื่อ และปิดนำทาง รุ่นเดิมปิดอัตโนมัติเฉพาะจุดหลัก needsBranch จึงอาจต้องเพิ่มการรองรับทั้ง popup/dialog ของสถานที่
- syncOsmPins แสดงรายการกรองรวมจุดหลัก setView(false) คือค่าเริ่มต้น fitOsm(false) เดิมข้ามต้นทางขอนแก่น ปรับชื่อ/พื้นที่ตรงทริปใหม่
- คง attribution และ license OpenStreetMap/Leaflet ตรวจนโยบาย tile ปัจจุบันเมื่อเปลี่ยนใช้งาน ไม่ทำ bulk download หรืออ้าง offline พร้อมใช้

## ทริปใหม่

คัดลอกเฉพาะไฟล์เว็บที่จำเป็น ไม่คัดลอก .git/.agents/บันทึกส่วนตัวทั้งชุด สร้างสารบัญ รายละเอียด บันทึกพิกัดใหม่ก่อน generate ปรับชื่อเว็บ จุดหลัก โซน หมวด ป้ายภาพวาด ค่า fit map และ manifest ไม่เก็บร้านหรือพิกัดเขาใหญ่เป็นค่าซ่อนอยู่

สกิลเป็นวิธีทำ ไม่ใช่ฐานข้อมูลสถานที่ปัจจุบัน ไม่ต้องแก้ทุกครั้งที่เพิ่มจุด
