# รูปแบบไฟล์สถานที่

ใช้สร้าง สถานที่/ID-place-slug.md สำหรับ generator เดิม ตัวอย่างเป็นแบบกรอก แทนข้อความและลิงก์ตัวอย่างก่อน generate:

```markdown
# [ชื่อสถานที่และสาขา]

ตรวจข้อมูล: [วันที่และขอบเขต]

## รู้จักสถานที่

[ประเภท ที่ตั้ง จุดเด่น]

## ไปแล้วทำอะไรได้

[กิจกรรมที่มีข้อมูลสนับสนุน]

## ข้อดี

- [จุดเด่นช่วยเลือกแวะ]

## ข้อเสียและข้อจำกัด

- [ข้อจำกัดที่เกี่ยวข้องจริง]

## ข้อควรระวัง

- [คำแนะนำสัมพันธ์กับพื้นที่/กิจกรรม]

## เหมาะกับใคร

[ผู้เที่ยวที่น่าจะชอบ]

## ข้อมูลสำหรับเลือกเที่ยว

- **พิกัดแสดงบนแผนที่:** [latitude], [longitude]
- **คำค้นแผนที่:** [latitude],[longitude]
- **ขอบเขตหมุด:** [ชี้ส่วนใด ใช้เป็นประตู/ที่จอดได้หรือไม่]
- **โซน:** [อำเภอ/พื้นที่หลัก] / [บริบทเส้นทาง]
- **ที่ตั้ง:** [ที่อยู่ตรวจแล้ว]
- **เวลาเผื่อเที่ยว:** [ช่วงเวลา] — ประมาณการเวลาเที่ยว ไม่รวมขับหรืออ้อม

## ผลตรวจสอบ

[หลักฐานชื่อ สาขา ที่อยู่ พิกัด และความไม่แน่นอน]

## แผนที่

[Google Maps](https://www.google.com/maps?cid=REPLACE_WITH_CONFIRMED_CID)

## แหล่งข้อมูล

- [ข้อมูลจากแหล่งที่ตรวจ](https://example.org/replace-with-source)
- [หมุดที่ตรวจ](https://www.google.com/maps?cid=REPLACE_WITH_CONFIRMED_CID)

[กลับสารบัญ](../README.md)
```

## เงื่อนไข

- หัวข้อรายละเอียด 6 หัวข้อแรกจำเป็น ข้อดี/ข้อเสีย/ข้อควรระวังใช้ bullet '- ' อย่างน้อยหนึ่งข้อที่มีสาระ ไม่แต่งข้อเสียเพื่อผ่าน parser
- เพิ่ม '## สถานะที่ควรรู้' เมื่อมีประกาศปิด ปรับปรุง หรือข้อจำกัด ระบุวันที่/แหล่งข้อมูล ไม่รับรองเปิดโดยไม่มีหลักฐาน
- ถ้าไม่มีพิกัด ตัดบรรทัดพิกัดออกทั้งบรรทัด ใช้ชื่อ/สาขาในคำค้นกับลิงก์ค้นหา Google Maps แทน CID ปลอม ระบุรอยืนยันและปิดนำทางตาม workspace-web.md
- โซนต้องมีค่า filter ใช้ส่วนหน้า '/' เป็นโซนหลัก
- Field ต้องตรง รูป '- **ชื่อ field:** ค่า' พิกัดเป็นตัวเลขคู่ comma-separated ไม่มีข้อความต่อท้าย
- พิกัดถูกไม่ยืนยันเปิดวันเดินทาง ตรวจสถานะแยก
- อ้างหน้าที่สนับสนุนข้อมูลจริง ไม่ใช้ search result เป็นหลักฐาน
